# crewbox

Offline-first crew communication for temporary events — chat and push-to-talk voice
as the core, with specialised department modules (patch sheets first) in one app,
served from one box on the venue network.

Crewbox unifies [inter](https://github.com/legofsalmon/inter) and
[Live Patch](https://github.com/legofsalmon/livepatch). See
[docs/UNIFICATION_PLAN.md](docs/UNIFICATION_PLAN.md) for the plan.
