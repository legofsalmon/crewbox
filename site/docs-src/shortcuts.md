# Keyboard shortcuts

`⌘` on a Mac, `Ctrl` everywhere else.

## Anywhere

| Keys    | Does                                                                   |
| ------- | ---------------------------------------------------------------------- |
| `⌘K`    | Open search                                                            |
| `Enter` | Send the message you're typing (computers; phones use the send button) |

## Patch sheet

| Keys            | Does                            |
| --------------- | ------------------------------- |
| `⌘F`            | Jump to the sheet's Find box    |
| `Enter` in Find | Next match (scrolled into view) |
| `⌘Z`            | Undo                            |
| `⌘⇧Z` or `⌘Y`   | Redo                            |

In the grid:

| Keys               | Does                              |
| ------------------ | --------------------------------- |
| Arrow keys         | Move between cells                |
| `Enter` / `⇧Enter` | Commit and move down / up         |
| `⌘D`               | Fill this cell from the one above |
| `Escape`           | Throw away your edit to this cell |

## Lighting plot

| Keys  | Does |
| ----- | ---- |
| `⌘Z`  | Undo |
| `⌘⇧Z` | Redo |

## Docs (this site)

| Keys            | Does                          |
| --------------- | ----------------------------- |
| `/` or `⌘K`     | Focus the docs search         |
| `↑` `↓` `Enter` | Move through and open results |

A note on undo: while you're typing in a text field, `⌘Z` is the normal
text-editing undo; the sheet- and plot-level undo takes over once the edit
is committed. Undo is per-device — your `⌘Z` never reverts something a
colleague just did on their phone.
