    Keyboard shortcuts

    ⌘ on a Mac, Ctrl everywhere else.

    Anywhere

    KeysDoes
    ⌘KOpen search
    EnterSend the message you're typing (computers; phones use the send button)

    Patch sheet

    KeysDoes
    ⌘FJump to the sheet's Find box
    Enter in FindNext match (scrolled into view)
    ⌘ZUndo
    ⌘⇧Z or ⌘YRedo

    In the grid:

    KeysDoes
    Arrow keysMove between cells
    Enter / ⇧EnterCommit and move down / up
    ⌘DFill this cell from the one above
    EscapeThrow away your edit to this cell

    Lighting plot

    KeysDoes
    ⌘ZUndo
    ⌘⇧ZRedo

    Docs (this site)

    KeysDoes
    / or ⌘KFocus the docs search
    ↑ ↓ EnterMove through and open results

    A note on undo: while you're typing in a text field, ⌘Z is the normal text-editing undo; the sheet- and plot-level undo takes over once the edit is committed. Undo is per-device — your ⌘Z never reverts something a colleague just did on their phone.
